# 🔍 ДЕТАЛЬНЫЙ РАЗБОР `ARRAY['a']::varchar[] AS visited_cities`

---

## 📖 РАЗБОР ПО ЧАСТЯМ

```sql
ARRAY['a']::varchar[]  AS visited_cities
  │    │    │   │        │      │
  │    │    │   │        │      └─── Имя колонки (название)
  │    │    │   │        │
  │    │    │   │        └────────── Ключевое слово "назовём как"
  │    │    │   │
  │    │    │   └─────────────────── Тип: массив строк
  │    │    │
  │    │    └─────────────────────── Оператор приведения типа
  │    │
  │    └──────────────────────────── Содержимое: элемент 'a'
  │
  └───────────────────────────────── Ключевое слово "создать массив"
```

---

## 🎯 ЧТО ЭТО ДЕЛАЕТ?

### Пошагово:

```sql
ARRAY['a']           -- Шаг 1: Создаём массив с одним элементом 'a'
         │
         ↓
::varchar[]          -- Шаг 2: Явно указываем тип "массив varchar"
         │
         ↓
AS visited_cities    -- Шаг 3: Даём этому массиву имя "visited_cities"
```

---

## 🔢 ШАГ 1: `ARRAY['a']` — Создание массива

### Что это:

```sql
ARRAY['a']
  │    │
  │    └─── Элемент массива (строка 'a')
  │
  └──────── Ключевое слово PostgreSQL для создания массива
```

### Результат:

```
Создаётся массив с одним элементом: ['a']

В PostgreSQL отображается как: {a}
```

### Примеры:

```sql
-- Один элемент
ARRAY['a']                    → {a}

-- Несколько элементов
ARRAY['a', 'b']               → {a,b}
ARRAY['a', 'b', 'c']          → {a,b,c}

-- Числа
ARRAY[1, 2, 3]                → {1,2,3}

-- Пустой массив
ARRAY[]                       → {}
```

---

## 🔄 ШАГ 2: `::varchar[]` — Приведение типа

### Что такое `::`?

```sql
::     ← Оператор CAST (приведение типа)

Синтаксис:
значение::тип

Примеры:
5::text         → '5' (число в строку)
'5'::integer    → 5 (строка в число)
ARRAY['a']::varchar[]  → массив строк типа varchar
```

### Что такое `varchar[]`?

```sql
varchar[]
   │     │
   │     └─── [] означает "массив"
   │
   └───────── varchar = строка переменной длины

Читается: "массив строк переменной длины"
```

### Зачем нужно приведение?

```sql
-- БЕЗ приведения (PostgreSQL угадывает тип):
ARRAY['a']         → массив типа text[]

-- С приведением (явно указываем):
ARRAY['a']::varchar[]  → массив типа varchar[]

Зачем:
✅ Явная типизация (понятно, что хранится)
✅ Совместимость при операциях (|| и др.)
✅ Консистентность кода
```

---

## 📛 ШАГ 3: `AS visited_cities` — Имя колонки

### Что это:

```sql
AS visited_cities
│      │
│      └─── Новое имя (алиас)
│
└────────── Ключевое слово "назовём как"

Результат: колонка будет называться "visited_cities"
```

### Зачем нужно:

```sql
-- БЕЗ AS (PostgreSQL даст имя ?column?):
SELECT ARRAY['a']::varchar[];

-- С AS (даём понятное имя):
SELECT ARRAY['a']::varchar[] AS visited_cities;

Результат:
 visited_cities
----------------
 {a}
```

## 🔬 ДЕТАЛЬНЫЕ ПРИМЕРЫ

### Пример 1: Создание разных массивов

```sql
-- Массив из одного элемента
SELECT ARRAY['a']::varchar[] AS one_element;
-- Результат: {a}

-- Массив из нескольких элементов
SELECT ARRAY['a','b','c']::varchar[] AS multiple_elements;
-- Результат: {a,b,c}

-- Массив чисел
SELECT ARRAY[1,2,3]::integer[] AS numbers;
-- Результат: {1,2,3}

-- Пустой массив
SELECT ARRAY[]::varchar[] AS empty_array;
-- Результат: {}
```

### Пример 2: Без явного приведения типа

```sql
-- PostgreSQL сам определит тип
SELECT ARRAY['a'] AS cities;

-- Тип будет: text[] (не varchar[])
-- Это работает, но менее явно
```

### Пример 3: Разные способы указания типа

```sql
-- Способ 1: :: (короткий, используем мы)
SELECT ARRAY['a']::varchar[] AS visited;

-- Способ 2: CAST (длинный, стандарт SQL)
SELECT CAST(ARRAY['a'] AS varchar[]) AS visited;

-- Оба работают одинаково!
```

### В контексте рекурсии:

```sql
WITH RECURSIVE building_routes AS (
    -- ANCHOR MEMBER:
    SELECT
        ARRAY['a']::varchar[] AS visited_cities,  ← ЗДЕСЬ!
        'a'::CHAR(1)          AS current_city,
        0                     AS accumulated_cost
    
    UNION ALL
    
    -- RECURSIVE MEMBER:
    SELECT
        routes.visited_cities || ARRAY[edges.point2]::varchar[],
        ↑                                                │
        └────────────── используем массив, созданный выше
```

### Что происходит:

```
ИТЕРАЦИЯ 0 (anchor):
```

## 📊 ВИЗУАЛЬНОЕ СРАВНЕНИЕ ТИПОВ

```sql
-- Разные типы массивов:

ARRAY['a']::varchar[]     → массив varchar
ARRAY['a']::char(1)[]     → массив char(1)
ARRAY['a']::text[]        → массив text
ARRAY[1,2,3]::integer[]   → массив целых чисел
ARRAY[1.5,2.7]::numeric[] → массив дробных чисел
```

### Таблица типов:

| Выражение | Тип результата | Значение |
|-----------|----------------|----------|
| `ARRAY['a']` | text[] | {a} |
| `ARRAY['a']::varchar[]` | varchar[] | {a} |
| `ARRAY['a']::char(1)[]` | char(1)[] | {a} |
| `ARRAY[1,2,3]` | integer[] | {1,2,3} |

```sql
SELECT 
    ARRAY['a']::varchar[] AS значение,

-- Пример 5: Сравнение с другими типами

    'a'::varchar AS строка,
    ARRAY['a']::varchar[] AS массив,
    5::integer AS число;

-- Результат:
--  строка | массив | число
-- --------+--------+-------
--  a      | {a}    | 5
```

## 🔑 КЛЮЧЕВЫЕ МОМЕНТЫ

### 1. `ARRAY[...]` — создание массива

```sql
ARRAY['a']       → создаёт массив
ARRAY['a','b']   → создаёт массив
ARRAY[1,2,3]     → создаёт массив
```

### 2. `::тип` — приведение типа

```sql
значение::varchar[]    → "это массив varchar"
значение::integer[]    → "это массив integer"
```

### 3. `AS имя` — название колонки

```sql
... AS visited_cities  → колонка будет называться "visited_cities"
```
