Гамильтонов граф — граф, содержащий гамильтонов цикл[1]. При этом гамильтоновым циклом является такой цикл (замкнутый путь), который проходит через каждую вершину данного графа ровно по одному разу[2]; то есть простой цикл, в который входят все вершины графа.


Граф — математическая абстракция реальной системы любой природы, объекты которой обладают парными связями. Граф как математический объект есть совокупность двух множеств — множества самих объектов, называемого множеством вершин, и множества их парных связей, называемого множеством рёбер. Элемент множества рёбер есть пара элементов множества вершин.












# 🎯 ГАМИЛЬТОНОВЫ ЦИКЛЫ НАХОДЯТСЯ ЗДЕСЬ!

```sql
WITH RECURSIVE building_routes AS (
    -- ❌ Здесь НЕ гамильтоновы циклы
    -- Здесь все возможные НЕЗАВЕРШЁННЫЕ маршруты
    -- Например: ['a'], ['a','b'], ['a','b','c'], ...
    ...
),

╔═══════════════════════════════════════════════════════╗
║  ✅ ЗДЕСЬ ФОРМИРУЮТСЯ ГАМИЛЬТОНОВЫ ЦИКЛЫ!            ║
║  ═════════════════════════════════════════════════   ║
║  CTE: complete_cycles                                ║
╚═══════════════════════════════════════════════════════╝

complete_cycles AS (
    SELECT
        routes.accumulated_cost + return_edge.cost AS total_cost,
        '{' || array_to_string(routes.visited_cities || ARRAY['a']::varchar[], ',') || '}' AS tour
    FROM building_routes AS routes
    
    -- ┌──────────────────────────────────────────┐
    -- │ ЗДЕСЬ ЗАМЫКАЕМ ЦИКЛ (возврат в 'a')     │
    -- └──────────────────────────────────────────┘
    JOIN tsp AS return_edge 
      ON return_edge.point1 = routes.current_city 
     AND return_edge.point2 = 'a'  -- ← Возвращаемся в начало!
    
    -- ┌──────────────────────────────────────────┐
    -- │ ПРОВЕРЯЕМ ПОЛНОТУ (все города посещены) │
    -- └──────────────────────────────────────────┘
    WHERE array_length(routes.visited_cities, 1) = (
        SELECT COUNT(DISTINCT point1) FROM tsp
    )
    
    -- ✅ Результат: ТОЛЬКО гамильтоновы циклы!
    -- Пример: {a,b,d,c,a}, {a,c,d,b,a}
)

-- ❌ Здесь уже готовые гамильтоновы циклы
-- Только фильтруем их по минимальной стоимости
SELECT total_cost, tour
FROM complete_cycles
WHERE total_cost = (SELECT MIN(total_cost) FROM complete_cycles)
ORDER BY total_cost, tour;
```

## 🔍 ДЕТАЛЬНЫЙ РАЗБОР

### 1️⃣ **building_routes** — НЕ гамильтоновы циклы

```sql
building_routes
↓
Содержит ВСЕ частичные маршруты:
['a']           ← 1 город
['a','b']       ← 2 города
['a','b','c']   ← 3 города
['a','b','c','d'] ← 4 города (но НЕ цикл - нет возврата!)
...
```

**Это НЕ циклы**, потому что:
- ❌ Не обязательно все города посещены
- ❌ Нет возврата в 'a'

---

### 2️⃣ **complete_cycles** — ЗДЕСЬ гамильтоновы циклы! ✅

```sql
complete_cycles
↓
Берём маршруты из building_routes:
['a','b','c','d']  ← пока не цикл

Добавляем возврат:
['a','b','c','d','a']  ← теперь цикл!

Проверяем полноту:
array_length(['a','b','c','d'], 1) = 4  ← все города посещены!

Результат:
{a,b,c,d,a}  ← ГАМИЛЬТОНОВ ЦИКЛ!
```

## 📖 ОПРЕДЕЛЕНИЕ ГАМИЛЬТОНОВА ЦИКЛА

```
Гамильтонов цикл = цикл, который:
1. ✓ Проходит через ВСЕ вершины графа
2. ✓ Каждую вершину посещает РОВНО 1 РАЗ
3. ✓ Возвращается в начальную точку
```

**Где это проверяется в коде:**

```sql
complete_cycles AS (
    SELECT ...
    FROM building_routes AS routes
    
    -- ✓ Условие 3: Возврат в начало
    JOIN tsp AS return_edge 
      ON ... AND return_edge.point2 = 'a'
    
    -- ✓ Условие 1: Все вершины посещены
    WHERE array_length(routes.visited_cities, 1) = (
        SELECT COUNT(DISTINCT point1) FROM tsp
    )
    
    -- ✓ Условие 2: Каждая ровно 1 раз
    -- (гарантируется рекурсией в building_routes
    --  через WHERE NOT edges.point2 = ANY(...))
)
```

## 🎓 ПРОВЕРЬ СЕБЯ

**Вопрос:** Есть ли гамильтоновы циклы в `building_routes`?

**Ответ:** ❌ НЕТ! Там только частичные маршруты без возврата в 'a'.

---

**Вопрос:** Где именно формируется строка цикла `{a,b,d,c,a}`?

**Ответ:** В `complete_cycles`, в строке:
```sql
'{' || array_to_string(routes.visited_cities || ARRAY['a']::varchar[], ',') || '}'
```

---

**Вопрос:** Что делает условие `return_edge.point2 = 'a'`?

**Ответ:** Находит ребро для **возврата в начальную точку**, замыкая цикл.
