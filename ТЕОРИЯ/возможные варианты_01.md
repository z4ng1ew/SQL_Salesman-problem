## 📝 ИДЕАЛЬНАЯ ВЕРСИЯ team00_ex01.sql

```sql
-- ==========================================
-- TEAM00 Exercise 01: Opposite TSP
-- Вывод маршрутов с MIN и MAX стоимостью
-- 
-- Формат: Только DML (SELECT-запрос)
-- Использует таблицу tsp из ex00
-- ==========================================

WITH RECURSIVE tour AS (
    -- База рекурсии: начинаем с города 'a'
    SELECT
        ARRAY['a']::varchar[]  AS path,
        'a'::CHAR(1)           AS last_point,
        0                      AS total_cost
    
    UNION ALL
    
    -- Рекурсивный шаг: добавляем непосещённые города
    SELECT
        tour.path || ARRAY[tsp.point2]::varchar[],
        tsp.point2,
        tour.total_cost + tsp.cost
    FROM tour
    JOIN tsp ON tsp.point1 = tour.last_point
    WHERE NOT tsp.point2 = ANY(tour.path)
),
finished_tours AS (
    -- Завершаем туры возвратом в 'a'
    SELECT
        tour.total_cost + tsp.cost AS total_cost,
        '{' || array_to_string(tour.path || ARRAY['a']::varchar[], ',') || '}' AS tour
    FROM tour
    JOIN tsp 
      ON tsp.point1 = tour.last_point 
     AND tsp.point2 = 'a'
    WHERE array_length(tour.path, 1) = (
        SELECT COUNT(DISTINCT point1) FROM tsp
    )
)
-- Выбираем маршруты с MIN и MAX стоимостью
SELECT total_cost, tour
FROM finished_tours
WHERE total_cost = (SELECT MIN(total_cost) FROM finished_tours)
   OR total_cost = (SELECT MAX(total_cost) FROM finished_tours)
ORDER BY total_cost, tour;
```

## 🔍 ПОЧЕМУ ЭТО ИДЕАЛЬНОЕ РЕШЕНИЕ?

### 1️⃣ **Соответствие требованиям:**

- ✅ ANSI SQL синтаксис
- ✅ Правильная сортировка

### 2️⃣ **Правильный формат вывода:**

- ✅ Фигурные скобки `{}`

## 🎯 АЛЬТЕРНАТИВНАЯ ВЕРСИЯ (С CTE filtered)

Если хочешь более структурированный подход:

```sql
WITH RECURSIVE tour AS (
    SELECT
        ARRAY['a']::varchar[]  AS path,
        'a'::CHAR(1)           AS last_point,
        0                      AS total_cost
    UNION ALL
    SELECT
        tour.path || ARRAY[tsp.point2]::varchar[],
        tsp.point2,
        tour.total_cost + tsp.cost
    FROM tour
    JOIN tsp ON tsp.point1 = tour.last_point
    WHERE NOT tsp.point2 = ANY(tour.path)
),
finished_tours AS (
    SELECT
        tour.total_cost + tsp.cost AS total_cost,
        '{' || array_to_string(tour.path || ARRAY['a']::varchar[], ',') || '}' AS tour
    FROM tour
    JOIN tsp 
      ON tsp.point1 = tour.last_point 
     AND tsp.point2 = 'a'
    WHERE array_length(tour.path, 1) = (
        SELECT COUNT(DISTINCT point1) FROM tsp
    )
),
filtered AS (
    SELECT total_cost, tour
    FROM finished_tours
    WHERE total_cost = (SELECT MIN(total_cost) FROM finished_tours)
       OR total_cost = (SELECT MAX(total_cost) FROM finished_tours)
)
SELECT total_cost, tour
FROM filtered
ORDER BY total_cost, tour;
```

**Разница:** Добавлен промежуточный CTE `filtered` для лучшей читаемости.
