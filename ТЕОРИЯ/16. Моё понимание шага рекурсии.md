### ❌ ОШИБКА 1: "ARRAY[edges.point2] - новыЕ городА"

```
НЕ множественное число!
```

#### Почему:

```sql
edges.point2 - это ОДНО значение (один город)
ARRAY[edges.point2] - массив с ОДНИМ элементом

Примеры:
edges.point2 = 'c'
ARRAY['c'] = {c}  ← массив с ОДНИМ городом!

Не:
ARRAY['c', 'd', 'b']  ← несколько городов ❌
```

#### Как это работает:

```sql
-- Итерация JOIN создаёт ОТДЕЛЬНЫЕ строки для каждого города:

Из {a,b} JOIN находит:
• b→c (edges.point2 = 'c')  ← одна строка
• b→d (edges.point2 = 'd')  ← другая строка

Для каждой строки edges.point2 - это ОДИН город!

SELECT создаёт ДВЕ новые строки:
1. {a,b,c}  ← добавили 'c'
2. {a,b,d}  ← добавили 'd'
```

```sql
    0 AS accumulated_cost

-- В recursive member имена берутся из anchor!

    routes.visited_cities || ...,  ← станет visited_cities
    edges.point2,                  ← станет current_city
    routes.accumulated_cost + ...  ← станет accumulated_cost
```

```sql
-- 6. Фильтр: не идём в посещённые города
WHERE NOT edges.point2 = ANY(routes.visited_cities)
```
