# 🎯 EXCEPT vs UNION vs JOIN - ФУНДАМЕНТАЛЬНОЕ РАЗЛИЧИЕ!

## 💡 Главное отличие

### EXCEPT и UNION = операции над **МНОЖЕСТВАМИ** (работают **ВЕРТИКАЛЬНО**)
### JOIN = операция **СОЕДИНЕНИЯ** (работает **ГОРИЗОНТАЛЬНО**)

---

## 📊 Визуализация различий

### EXCEPT и UNION - добавляют/убирают СТРОКИ ↕️

```
Таблица A          Таблица B
┌─────┐            ┌─────┐
│  1  │            │  2  │
│  2  │            │  3  │
│  3  │            │  4  │
└─────┘            └─────┘
   ↓                  ↓
   └──── UNION ───────┘
          ↓
      ┌─────┐
      │  1  │  ← все строки
      │  2  │    из A и B
      │  3  │    (без дубликатов)
      │  4  │
      └─────┘

   ↓
   └──── EXCEPT ──────┐
          ↓           ✗ (убираем B)
      ┌─────┐
      │  1  │  ← только из A,
      └─────┘    которых нет в B
```

### JOIN - добавляет КОЛОНКИ ↔️

```
Таблица A          Таблица B
┌────┬──────┐      ┌────┬──────┐
│ id │ name │      │ id │ city │
├────┼──────┤      ├────┼──────┤
│ 1  │ Anna │      │ 1  │ NY   │
│ 2  │ Bob  │      │ 2  │ LA   │
└────┴──────┘      └────┴──────┘
       ↓                ↓
       └──── JOIN ──────┘
              ↓
      ┌────┬──────┬──────┐
      │ id │ name │ city │  ← колонки
      ├────┼──────┼──────┤    рядом
      │ 1  │ Anna │ NY   │
      │ 2  │ Bob  │ LA   │
      └────┴──────┴──────┘
```

---

## 🔍 ДЕТАЛЬНОЕ СРАВНЕНИЕ

### 1️⃣ UNION - объединение множеств

**Что делает:** Склеивает строки из двух таблиц **ВЕРТИКАЛЬНО**

```sql
-- UNION
SELECT name FROM females  -- Anna, Kate
UNION
SELECT name FROM males;   -- Bob, Denis

-- Результат:
┌────────┐
│ Anna   │  ← из females
│ Kate   │  ← из females
│ Bob    │  ← из males
│ Denis  │  ← из males
└────────┘

4 строки, 1 колонка
```

**Математика:** A ∪ B (объединение)
**Аналогия:** Соединить два списка в один

---

### 2️⃣ EXCEPT - разность множеств

**Что делает:** Вычитает строки из первой таблицы, которые есть во второй

```sql
-- EXCEPT
SELECT name FROM females  -- Anna, Kate, Mary
EXCEPT
SELECT name FROM males;   -- Bob, Denis

-- Результат:
┌────────┐
│ Anna   │  ← была в females, нет в males
│ Kate   │  ← была в females, нет в males
│ Mary   │  ← была в females, нет в males
└────────┘

3 строки, 1 колонка
```

**Математика:** A \ B (разность)
**Аналогия:** Убрать из первого списка всё, что есть во втором

---

### 3️⃣ JOIN - соединение таблиц

**Что делает:** Склеивает колонки из двух таблиц **ГОРИЗОНТАЛЬНО**

```sql
-- JOIN
SELECT p.name, c.city
FROM persons p
JOIN cities c ON p.city_id = c.id;

-- Результат:
┌────────┬────────┐
│ name   │ city   │  ← колонки рядом
├────────┼────────┤
│ Anna   │ NY     │
│ Bob    │ LA     │
└────────┴────────┘

2 строки, 2 колонки
```

**Математика:** Декартово произведение + фильтр
**Аналогия:** Приклеить вторую таблицу справа от первой

---

## 📐 Таблица сравнения

| Операция | Направление | Что делает | Строки | Колонки | Математика |
|----------|-------------|------------|--------|---------|------------|
| **UNION** | ↕️ Вертикально | Объединяет строки | Больше | Те же | A ∪ B |
| **EXCEPT** | ↕️ Вертикально | Вычитает строки | Меньше | Те же | A \ B |
| **JOIN** | ↔️ Горизонтально | Склеивает колонки | По условию | Больше | A ⨝ B |

---

## 🍕 Аналогия с пиццами

### UNION - складываем пиццы в стопку:

```
Пицца 1: Маргарита
Пицца 2: Пепперони
         ↓ UNION
Стопка:  Маргарита  ← сверху
         Пепперони  ← снизу

Высота стопки = 2 пиццы
```

---

### EXCEPT - убираем пиццы:

```
У тебя:    Маргарита, Пепперони, Гавайская
Съел:      Пепперони
           ↓ EXCEPT
Осталось:  Маргарита, Гавайская

Убрали то, что съели
```

---

### JOIN - кладём ингредиенты рядом:

```
База пиццы:  [тесто]
Топпинги:    [сыр] [помидоры] [базилик]
             ↓ JOIN
Готовая:     [тесто][сыр][помидоры][базилик]

Добавили ингредиенты справа
```

## 💻 Примеры на реальных данных

### Исходные данные:

```sql
-- Таблица visits_jan_02 (кто был 2 января)
┌───────────┐
│ person_id │
├───────────┤
│     2     │ ← Andrey
│     5     │ ← Bob
└───────────┘

-- Таблица visits_jan_06 (кто был 6 января)
┌───────────┐
│ person_id │
├───────────┤
│     5     │ ← Bob
│     8     │ ← Nataly
└───────────┘

-- Таблица person (справочник людей)
┌────┬────────┐
│ id │ name   │
├────┼────────┤
│ 2  │ Andrey │
│ 5  │ Bob    │
│ 8  │ Nataly │
└────┴────────┘
```

---

### 1️⃣ UNION - все, кто был 2-го ИЛИ 6-го:

```sql
SELECT person_id FROM visits_jan_02  -- {2, 5}
UNION
SELECT person_id FROM visits_jan_06; -- {5, 8}

-- Результат (вертикально):
┌───────────┐
│ person_id │
├───────────┤
│     2     │ ← был 2-го
│     5     │ ← был оба дня (один раз в результате)
│     8     │ ← был 6-го
└───────────┘

3 строки, 1 колонка
```

**Читается:** "Покажи всех, кто был хоть раз"

---

### 2️⃣ EXCEPT - кто был 2-го, но НЕ 6-го:

```sql
SELECT person_id FROM visits_jan_02  -- {2, 5}
EXCEPT
SELECT person_id FROM visits_jan_06; -- {5, 8}

-- Результат (вертикально):
┌───────────┐
│ person_id │
├───────────┤
│     2     │ ← был 2-го, не был 6-го
└───────────┘

1 строка, 1 колонка
```

**Читается:** "Покажи тех, кто был 2-го, но вычти тех, кто был 6-го"

---

### 3️⃣ JOIN - кто был 2-го С ИМЕНАМИ:

```sql
SELECT v.person_id, p.name
FROM visits_jan_02 v
JOIN person p ON p.id = v.person_id;

-- Результат (горизонтально):
┌───────────┬────────┐
│ person_id │ name   │ ← колонки рядом!
├───────────┼────────┤
│     2     │ Andrey │
│     5     │ Bob    │
└───────────┴────────┘

2 строки, 2 колонки
```

**Читается:** "Для каждого визита покажи имя человека"

## 🧩 Когда что использовать?

### Используй UNION, если нужно:

✅ Объединить списки  
✅ Склеить результаты нескольких запросов  
✅ "Покажи А ИЛИ Б"

**Примеры:**
- Все клиенты из России ИЛИ США
- Заказы января ИЛИ февраля
- Активные пользователи ИЛИ премиум пользователи

```sql
SELECT name FROM customers_russia
UNION
SELECT name FROM customers_usa;
```

---

### Используй EXCEPT, если нужно:

✅ Найти различия  
✅ Исключить подмножество  
✅ "Покажи А, но без Б"

**Примеры:**
- Все даты января КРОМЕ дней с посещениями
- Клиенты, которые НЕ делали заказы
- Пользователи 2022 года, которых НЕТ в 2023

```sql
SELECT date FROM all_january_dates
EXCEPT
SELECT visit_date FROM visits;
```

---

### Используй JOIN, если нужно:

✅ Обогатить данными  
✅ Связать таблицы  
✅ "Добавь информацию из другой таблицы"

**Примеры:**
- Заказы С именами клиентов
- Товары С ценами
- Посещения С названиями пиццерий

```sql
SELECT o.id, p.name, o.date
FROM orders o
JOIN persons p ON p.id = o.person_id;
```

## 🎓 Требования к структуре

### UNION и EXCEPT - строгие!

```sql
-- ✅ ПРАВИЛЬНО - одинаковая структура:
SELECT name FROM table1        -- 1 колонка VARCHAR
UNION
SELECT name FROM table2;       -- 1 колонка VARCHAR

-- ❌ ОШИБКА - разное количество колонок:
SELECT name, age FROM table1   -- 2 колонки
UNION
SELECT name FROM table2;       -- 1 колонка
-- ERROR: queries must have same number of columns

-- ❌ ОШИБКА - несовместимые типы:
SELECT name FROM table1        -- VARCHAR
UNION
SELECT age FROM table2;        -- INTEGER
-- ERROR: UNION types cannot be matched
```

---

### JOIN - гибкий!

```sql
-- ✅ Разное количество колонок - ОК:
SELECT *
FROM persons          -- 5 колонок
JOIN cities           -- 3 колонки
ON persons.city_id = cities.id;
-- Результат: 8 колонок (5 + 3)

-- ✅ Разные типы - ОК (если условие совместимо):
SELECT *
FROM orders           -- id: INTEGER
JOIN products         -- id: BIGINT
ON orders.product_id = products.id;
```

---

## 🔄 Можно ли заменить друг другом?

### ❌ UNION/EXCEPT НЕ заменяют JOIN:

```sql
-- НЕПРАВИЛЬНО (не то же самое):
SELECT person_id FROM visits
UNION
SELECT id FROM persons;
-- ↑ Просто список ID, БЕЗ связи!

-- ПРАВИЛЬНО:
SELECT v.person_id, p.name
FROM visits v
JOIN persons p ON p.id = v.person_id;
-- ↑ Связанные данные!
```

---

### ❌ JOIN НЕ заменяет UNION/EXCEPT:

```sql
-- Задача: найти все даты с посещениями
-- ПРАВИЛЬНО (UNION):
SELECT visit_date FROM visits_jan
UNION
SELECT visit_date FROM visits_feb;

-- НЕПРАВИЛЬНО (JOIN):
SELECT v1.visit_date, v2.visit_date
FROM visits_jan v1
JOIN visits_feb v2 ON ...;
-- ↑ Это ДЕКАРТОВО произведение, не список!
```

## 📋 Шпаргалка

| Операция | Аналогия | SQL | Результат |
|----------|----------|-----|-----------|
| **UNION** | Сложить стопку бумаг | `A UNION B` | Строки A + строки B |
| **EXCEPT** | Вычеркнуть из списка | `A EXCEPT B` | Строки A без строк B |
| **JOIN** | Склеить листы рядом | `A JOIN B` | Колонки A + колонки B |

## 🎯 Простой тест на понимание

### Вопрос: Что вернёт каждый запрос?

**Данные:**
```
Table1: {1, 2, 3}
Table2: {2, 3, 4}
```

```sql
-- 1. UNION
SELECT * FROM Table1 UNION SELECT * FROM Table2;
→ {1, 2, 3, 4}  ✅

-- 2. EXCEPT
SELECT * FROM Table1 EXCEPT SELECT * FROM Table2;
→ {1}  ✅

-- 3. JOIN (без условия - декартово произведение)
SELECT t1.*, t2.* FROM Table1 t1, Table2 t2;
→ 9 строк (3 × 3)  ✅
```

## 💡 Запомни навсегда:

```
UNION/EXCEPT = операции со СПИСКАМИ (↕️)
"Добавь строки" или "Убери строки"

JOIN = операция СКЛЕИВАНИЯ (↔️)
"Приклей колонки справа"

UNION: A и B → A+B (вертикально)
EXCEPT: A минус B → остаток A (вертикально)
JOIN: A и B → A⨝B (горизонтально)
```

**Главное:** UNION/EXCEPT меняют **количество строк**, JOIN меняет **количество колонок**! 🎯
