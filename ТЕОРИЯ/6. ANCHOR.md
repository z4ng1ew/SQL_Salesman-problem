# 🎯 ВОТ ГДЕ ANCHOR MEMBER!

```sql
WITH RECURSIVE building_routes AS (

    -- ============================================
    -- ЭТО ANCHOR MEMBER (БАЗОВЫЙ/ВЕДУЩИЙ ЧЛЕН)
    -- Начальная точка рекурсии
    -- Выполняется ОДИН РАЗ в самом начале
    -- ============================================
    SELECT
        ARRAY['a']::varchar[]  AS visited_cities,
        'a'::CHAR(1)           AS current_city,
        0                      AS accumulated_cost
    
    -- ============================================
    -- ГРАНИЦА между anchor и recursive member
    -- ============================================
    UNION ALL
    -- ============================================
    
    -- ============================================
    -- ЭТО RECURSIVE MEMBER (РЕКУРСИВНЫЙ ЧЛЕН)
    -- Повторяющаяся часть рекурсии
    -- Выполняется МНОГОКРАТНО, пока есть новые строки
    -- ============================================
    SELECT
        routes.visited_cities || ARRAY[edges.point2]::varchar[],
        edges.point2,
        routes.accumulated_cost + edges.cost
    FROM building_routes AS routes  -- ← ссылается на СЕБЯ (рекурсия!)
    JOIN tsp AS edges ON edges.point1 = routes.current_city
    WHERE NOT edges.point2 = ANY(routes.visited_cities)
)
```

## 📖 СТРУКТУРА РЕКУРСИВНОГО CTE

```sql
WITH RECURSIVE имя_CTE AS (
    
    ┌─────────────────────────────────┐
    │   ANCHOR MEMBER                 │  ← БАЗА РЕКУРСИИ
    │   (базовый/ведущий член)        │  ← Выполняется 1 раз
    │                                 │  ← НЕ ссылается на себя
    │   SELECT ... (начальные данные) │
    └─────────────────────────────────┘
    
    UNION ALL  ← ГРАНИЦА (обязательный разделитель)
    
    ┌─────────────────────────────────┐
    │   RECURSIVE MEMBER              │  ← РЕКУРСИВНЫЙ ШАГ
    │   (рекурсивный член)            │  ← Выполняется многократно
    │                                 │  ← Ссылается на СЕБЯ
    │   SELECT ... FROM имя_CTE ...   │
    └─────────────────────────────────┘
)
```

## 🔍 В ТВОЁМ КОДЕ ДЕТАЛЬНО

```sql
WITH RECURSIVE building_routes AS (

    ╔═══════════════════════════════════════════════════╗
    ║  ANCHOR MEMBER (ЯКОРНЫЙ/БАЗОВЫЙ ЧЛЕН)             ║
    ║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ║
    ║  Это "семя" рекурсии                              ║
    ║  Начальное состояние: стоим в городе 'a'          ║
    ║  Выполняется ТОЛЬКО ОДИН РАЗ                      ║
    ║  НЕ ссылается на building_routes                  ║
    ╚═══════════════════════════════════════════════════╝
    SELECT
        ARRAY['a']::varchar[]  AS visited_cities,  -- начальный массив
        'a'::CHAR(1)           AS current_city,    -- стартовый город
        0                      AS accumulated_cost -- стоимость = 0
    
    ╔═══════════════════════════════════════════════════╗
    ║              UNION ALL                            ║
    ║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ║
    ║  Объединяет anchor с recursive                    ║
    ║  ALL = не удалять дубликаты                       ║
    ╚═══════════════════════════════════════════════════╝
    UNION ALL
    
    ╔═══════════════════════════════════════════════════╗
    ║  RECURSIVE MEMBER (РЕКУРСИВНЫЙ ЧЛЕН)              ║
    ║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ║
    ║  Это "тело" рекурсии                              ║
    ║  Добавляет следующий город к маршруту             ║
    ║  Выполняется МНОГОКРАТНО (пока есть новые строки) ║
    ║  ССЫЛАЕТСЯ на building_routes (рекурсия!)         ║
    ╚═══════════════════════════════════════════════════╝
    SELECT
        routes.visited_cities || ARRAY[edges.point2]::varchar[],
        edges.point2,
        routes.accumulated_cost + edges.cost
    FROM building_routes AS routes  -- ← РЕКУРСИВНАЯ ССЫЛКА!
    JOIN tsp AS edges ON edges.point1 = routes.current_city
    WHERE NOT edges.point2 = ANY(routes.visited_cities)
),
```

## 🎬 КАК ЭТО РАБОТАЕТ ПОШАГОВО

### Шаг 0: ANCHOR MEMBER выполняется первым

```
ИТЕРАЦИЯ 0 (anchor):
┌─────────────────┬──────────────┬──────────────────┐
│ visited_cities  │ current_city │ accumulated_cost │
├─────────────────┼──────────────┼──────────────────┤
│ ['a']           │ 'a'          │ 0                │
└─────────────────┴──────────────┴──────────────────┘
```

### Шаг 1: RECURSIVE MEMBER использует результат anchor

```
ИТЕРАЦИЯ 1 (recursive):
Из anchor взяли ['a'], current='a'
→ Присоединили рёбра из 'a': к b, c, d
┌─────────────────┬──────────────┬──────────────────┐
│ ['a','b']       │ 'b'          │ 10               │
│ ['a','c']       │ 'c'          │ 15               │
│ ['a','d']       │ 'd'          │ 20               │
└─────────────────┴──────────────┴──────────────────┘
```

### Шаг 2: RECURSIVE MEMBER использует результат предыдущей итерации

```
ИТЕРАЦИЯ 2 (recursive):
Взяли результаты итерации 1
→ Продолжили добавлять города
┌─────────────────┬──────────────┬──────────────────┐
│ ['a','b','c']   │ 'c'          │ 45               │
│ ['a','b','d']   │ 'd'          │ 35               │
│ ['a','c','b']   │ 'b'          │ 50               │
│ ['a','c','d']   │ 'd'          │ 45               │
│ ...             │ ...          │ ...              │
└─────────────────┴──────────────┴──────────────────┘
```

## 🔑 КЛЮЧЕВЫЕ ОТЛИЧИЯ

| Характеристика | ANCHOR MEMBER | RECURSIVE MEMBER |
|----------------|---------------|------------------|
| **Позиция** | ПЕРЕД UNION ALL | ПОСЛЕ UNION ALL |
| **Выполнение** | 1 раз (в начале) | Многократно |
| **Ссылается на себя?** | ❌ НЕТ | ✅ ДА (FROM building_routes) |
| **Назначение** | Начальное состояние | Расширение результата |
| **Аналогия** | База индукции (математика) | Шаг индукции |
| **Аналогия в C** | `int i = 0;` | `i++;` в цикле |

## 💡 АНАЛОГИЯ С ЦИКЛОМ

```javascript
// Рекурсивный CTE ≈ цикл while

// ANCHOR MEMBER (начальное состояние)
let routes = [{ path: ['a'], current: 'a', cost: 0 }];

// RECURSIVE MEMBER (тело цикла)
while (routes.length > 0) {
    let newRoutes = [];
    for (let route of routes) {
        // Ищем непосещённые города
        for (let edge of edges where edge.from === route.current) {
            if (!route.path.includes(edge.to)) {
                newRoutes.push({
                    path: [...route.path, edge.to],
                    current: edge.to,
                    cost: route.cost + edge.cost
                });
            }
        }
    }
    routes = newRoutes;  // следующая итерация
}
```

## ✅ ПРОВЕРЬ СЕБЯ

### Вопрос 1: Где anchor member в этом коде?

```sql
WITH RECURSIVE numbers AS (
    SELECT 1 AS n     -- ← ???
    UNION ALL
    SELECT n + 1      -- ← ???
    FROM numbers
    WHERE n < 10
)
```

**Ответ:** 
- `SELECT 1 AS n` — ANCHOR MEMBER
- `SELECT n + 1 FROM numbers` — RECURSIVE MEMBER

---

### Вопрос 2: Почему anchor member не ссылается на себя?

**Ответ:** Потому что это НАЧАЛЬНАЯ ТОЧКА рекурсии. Если бы он ссылался на себя, откуда бы взялись начальные данные? Это как база индукции в математике.

---

### Вопрос 3: Сколько раз выполняется anchor member?

**Ответ:** **ОДИН РАЗ** в самом начале. Recursive member выполняется многократно.

## 🎯 ИТОГОВАЯ СХЕМА ТВОЕГО КОДА

```sql
WITH RECURSIVE building_routes AS (

    ▼ ANCHOR MEMBER (якорный член)
    ╔═══════════════════════════════════╗
    ║ SELECT                            ║
    ║     ARRAY['a']::varchar[],        ║ ← Начало
    ║     'a'::CHAR(1),                 ║ ← 1 раз
    ║     0                             ║ ← Не ссылается на себя
    ╚═══════════════════════════════════╝
    
    ═══════ UNION ALL ═══════  (граница)
    
    ▼ RECURSIVE MEMBER (рекурсивный член)
    ╔═══════════════════════════════════╗
    ║ SELECT                            ║
    ║     routes.visited_cities || ..., ║ ← Расширение
    ║     edges.point2,                 ║ ← Многократно
    ║     routes.accumulated_cost + ... ║ ← Ссылается на себя!
    ║ FROM building_routes AS routes    ║ ← ВОТ РЕКУРСИЯ!
    ║ JOIN tsp AS edges ...             ║
    ║ WHERE ...                         ║
    ╚═══════════════════════════════════╝
)
```

---

**Теперь ты точно знаешь, где что находится!** 🏆

**ANCHOR = база = начало = первый SELECT до UNION ALL**  
**RECURSIVE = шаг = повтор = второй SELECT после UNION ALL**
