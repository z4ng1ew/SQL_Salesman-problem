## 📋 ДЕТАЛЬНОЕ РАСПРЕДЕЛЕНИЕ

### 🟢 ТОВАРИЩ 2 (слабый) — ЧАСТЬ 1

#### Что рассказывать:

```sql
-- 1. Создание таблицы
DROP TABLE IF EXISTS tsp CASCADE;
CREATE TABLE tsp (
    point1 CHAR(1),  -- откуда
    point2 CHAR(1),  -- куда
    cost   INT       -- стоимость
);

-- 2. Заполнение данных
INSERT INTO tsp VALUES
('a','b',10), ('b','a',10),
...;
```

#### Что должен знать:

✅ **Обязательно:**
- Что такое TSP (Traveling Salesman Problem - задача коммивояжёра)
- Что такое CHAR(1) и INT
- Почему каждое ребро записано дважды (неориентированный граф)
- Зачем DROP TABLE IF EXISTS

✅ **Желательно:**
- Сколько всего рёбер (12 строк = 6 рёбер × 2)
- Какие города (a, b, c, d)
- Самое дешёвое ребро (a↔b = 10)
- Самое дорогое ребро (b↔c = 35)

❌ **НЕ обязательно:**
- Детали рекурсии
- Как работают массивы
- Сложные JOIN

#### Возможные вопросы для него:

```
Q: Что такое TSP?
A: Traveling Salesman Problem - задача коммивояжёра

Q: Зачем два раза пишем a→b и b→a?
A: Граф неориентированный, можно ходить в обе стороны

Q: Что означает point1 и point2?
A: point1 - откуда, point2 - куда

Q: Почему CHAR(1), а не VARCHAR?
A: Города - это всегда 1 буква, фиксированная длина эффективнее

Q: Сколько городов в графе?
A: 4 города: a, b, c, d
```

### 🔴 ТЫ (сильный) — ЧАСТЬ 2

#### Что рассказывать:

```sql
WITH RECURSIVE building_routes AS (
    -- Anchor member
    SELECT
        ARRAY['a']::varchar[]  AS visited_cities,
        'a'::CHAR(1)           AS current_city,
        0                      AS accumulated_cost
    
    UNION ALL
    
    -- Recursive member
    SELECT
        routes.visited_cities || ARRAY[edges.point2]::varchar[],
        edges.point2,
        routes.accumulated_cost + edges.cost
    FROM building_routes AS routes
    JOIN tsp AS edges ON edges.point1 = routes.current_city
    WHERE NOT edges.point2 = ANY(routes.visited_cities)
)
```

#### Что должен знать:

✅ **КРИТИЧЕСКИ важно:**
- Что такое WITH RECURSIVE
- Отличие anchor от recursive member
- Как работает UNION ALL
- Что такое массивы в PostgreSQL
- Оператор || (конкатенация)
- Оператор ANY
- Как работает JOIN
- Почему это граф в глубину (DFS)
- Условие остановки рекурсии

✅ **Дополнительно:**
- Сколько итераций (4 максимум для 4 городов)
- Примеры промежуточных состояний
- Почему varchar[], а не char(1)[]

#### Возможные сложные вопросы:

```
Q: Как работает рекурсия?
A: 1) Anchor создаёт начальное состояние ['a']
   2) Recursive добавляет следующие города
   3) Повторяется, пока есть непосещённые города

Q: Зачем NOT ... = ANY(...)?
A: Проверяем, не посещали ли уже этот город
   Чтобы не было циклов типа a→b→a→b

Q: Что будет, если убрать WHERE?
A: Бесконечная рекурсия, будем ходить по кругу

Q: Почему UNION ALL, а не UNION?
A: ALL сохраняет дубликаты, нужны все варианты путей

Q: Сколько строк создаст рекурсия?
A: Все возможные частичные маршруты
   Для 4 городов: 4 + 12 + 24 + 24 = 64 строки
```

### 🟡 ТОВАРИЩ 1 (второй сильный) — ЧАСТЬ 3

#### Что рассказывать:

```sql
complete_cycles AS (
    SELECT
        routes.accumulated_cost + return_edge.cost AS total_cost,
        '{' || array_to_string(routes.visited_cities || ARRAY['a']::varchar[], ',') || '}' AS tour
    FROM building_routes AS routes
    JOIN tsp AS return_edge 
      ON return_edge.point1 = routes.current_city 
     AND return_edge.point2 = 'a'
    WHERE array_length(routes.visited_cities, 1) = (
        SELECT COUNT(DISTINCT point1) FROM tsp
    )
)

SELECT total_cost, tour
FROM complete_cycles
WHERE total_cost = (SELECT MIN(total_cost) FROM complete_cycles)
ORDER BY total_cost, tour;
```

#### Что должен знать:

✅ **Обязательно:**
- Что такое гамильтонов цикл
- Зачем JOIN с tsp для возврата в 'a'
- Почему проверяем array_length
- Как работает array_to_string
- Зачем фигурные скобки в выводе
- Что делает подзапрос MIN
- Зачем ORDER BY

✅ **Дополнительно:**
- Почему COUNT(DISTINCT point1)
- Отличие ex00 от ex01 (MIN vs MIN+MAX)

#### Возможные вопросы:

```
Q: Что делает complete_cycles?
A: Замыкает маршруты в циклы (добавляет возврат в 'a')
   и фильтрует только полные (все города посещены)

Q: Зачем JOIN с return_edge?
A: Находим ребро для возврата в начальную точку 'a'

Q: Что означает array_length = COUNT?
A: Проверяем, что посетили ВСЕ города
   (длина массива = количество городов в графе)

Q: Зачем фигурные скобки?
A: Это формат вывода из задания: {a,b,d,c,a}

Q: Что делает MIN?
A: Находит минимальную стоимость среди всех циклов
```
